Integration tip for iOS: drop a set of SVGs Flat/fill/*-fill.svg into an asset catalog as template images (or a small Image("ph-star") wrapper). Keep one visual family (fill) across kid surfaces so pickers stay designed.
Filename quirk: regular is bare (star.svg); fill/bold/light/thin/duotone append a suffix (star-fill.svg). Prefer SVGs Flat/ when you need solid paths (asset-catalog friendly).
